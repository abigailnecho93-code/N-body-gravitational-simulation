# N-Body Gravitational Simulation and Numerical Stability Analysis

# Overview

This project investigates gravitational interactions using a Python-based N-body simulation, progressing from a two-body Sun–Earth system to a generalised multi-body model.

# Methods

* Implemented Euler and fourth-order Runge–Kutta (RK4) integration methods.
* Investigated orbital trajectories, total energy, angular momentum and relative energy error.
* Explored how timestep size affects numerical accuracy.
* Measured how simulation runtime changes with the number of bodies.

# Tools

Python, NumPy, Matplotlib, Jupyter Notebook.

# Main findings

The project compares numerical differentiation methods and investigates the trade-off between simulation accuracy and computational cost.
